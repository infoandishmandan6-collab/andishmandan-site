# بک‌اند سایت موسسه زبان اندیشمندان

این پروژه یک سرور Node.js + Express است که:
- سایت شما (index.html) را نمایش می‌دهد.
- اطلاعات ۴ فرم سایت را در یک دیتابیس SQLite ذخیره می‌کند.
- یک پنل مدیریت ساده در آدرس `/admin` دارد تا بتوانید درخواست‌های ارسالی را ببینید و مدیریت کنید.

## ساختار فرم‌ها

| فرم | جدول دیتابیس | آدرس API |
|---|---|---|
| فرم درخواست همکاری (مدرس/پرسنل/نمایندگی) | `collaborations` | `POST /api/collaboration` |
| فرم ثبت‌نام دانش‌آموز | `registrations` | `POST /api/registration` |
| فرم نظرات دانش‌آموزان | `testimonials` | `POST /api/testimonial` |
| فرم شکایات | `complaints` | `POST /api/complaint` |

## بخش‌های داینامیک سایت (اساتید، گالری، محتوا)

| بخش | جدول دیتابیس | API عمومی (نمایش در سایت) | API مدیریتی (ویرایش) |
|---|---|---|---|
| اساتید | `teachers` | `GET /api/teachers` | `/api/admin/teachers` |
| گالری | `gallery` | `GET /api/gallery` | `/api/admin/gallery` |
| محتوای متنی سایت | `site_content` | `GET /api/site-content` | `/api/admin/site-content/:key` |

فایل‌های آپلودشده (عکس اساتید و عکس/ویدیوی گالری) در پوشه `uploads/` ذخیره می‌شوند و از مسیر `/uploads/...` در دسترس هستند.

## نصب و اجرا (روی سیستم خودتان)

۱. مطمئن شوید Node.js نسخه ۱۸ به بالا نصب دارید.

۲. وارد پوشه پروژه شوید و پکیج‌ها را نصب کنید:
```bash
cd backend
npm install
```

۳. فایل تنظیمات را بسازید:
```bash
cp .env.example .env
```
سپس فایل `.env` را باز کنید و حتماً موارد زیر را عوض کنید:
- `ADMIN_USERNAME` و `ADMIN_PASSWORD` — نام کاربری و رمز پنل مدیریت
- `SESSION_SECRET` — یک رشته‌ی تصادفی و طولانی

۴. سرور را اجرا کنید:
```bash
npm start
```

۵. حالا می‌توانید به این آدرس‌ها بروید:
- سایت اصلی: `http://localhost:3000`
- پنل مدیریت: `http://localhost:3000/admin`

## پنل مدیریت

با نام کاربری و رمزی که در `.env` تنظیم کردید وارد شوید. در پنل می‌توانید:
- لیست هر ۴ فرم را جداگانه (با تب) ببینید
- وضعیت هر درخواست را تغییر دهید (جدید / بررسی‌شده / تکمیل‌شده)
- درخواست‌های غیرضروری را حذف کنید
- تعداد درخواست‌های جدید هر فرم را روی هر تب ببینید

### تب اساتید
افزودن، ویرایش و حذف اساتید همراه با آپلود عکس پروفایل. اطلاعات هر استاد (نام، نقش، بیوگرافی) به سه زبان فارسی/انگلیسی/پشتو قابل ثبت است. این اطلاعات به‌صورت خودکار در بخش «اساتید» سایت نمایش داده می‌شود.

### تب گالری
آپلود عکس یا ویدیو برای گالری سایت، همراه با توضیح اختیاری. آیتم‌های آپلودشده به‌صورت خودکار در بخش «گالری عکس و ویدیو» سایت نمایش داده می‌شوند.

### تب محتوای سایت
تقریباً تمام متن‌های سایت (عنوان‌ها، توضیحات، متن دکمه‌ها و...) در این بخش به تفکیک هر قسمت از سایت قابل ویرایش هستند — هرکدام به سه زبان. کافی است متن را عوض کرده و دکمه «ذخیره این متن» را بزنید؛ تغییر بلافاصله روی سایت اعمال می‌شود (با رفرش صفحه).

**نکته:** بخش‌های اساتید و گالری چون سیستم اختصاصی خودشان را دارند (تب‌های جداگانه)، در تب «محتوای سایت» ظاهر نمی‌شوند.

## دیتابیس

دیتابیس به‌صورت خودکار در مسیر `data/andishmandan.db` ساخته می‌شود و نیازی به نصب جداگانه‌ی هیچ نرم‌افزار دیتابیسی ندارید (SQLite یک فایل ساده است).

**نکته مهم:** حتماً از این فایل به‌صورت دوره‌ای نسخه پشتیبان (backup) بگیرید، چون تمام اطلاعات فرم‌های ارسالی در همین فایل ذخیره می‌شود.

## هاست کردن سایت (Deploy)

چون این پروژه یک سرور Node.js است (نه فقط یک فایل HTML ساده)، باید روی یک سرویس میزبانی که از Node.js پشتیبانی می‌کند اجرا شود. چند گزینه‌ی رایج و ساده:
- **Railway.app** یا **Render.com**: هر دو رایگان یا ارزان شروع می‌شوند و مستقیماً از یک پوشه پروژه Node.js دیپلوی می‌کنند.
- **یک VPS** (مثلاً با Nginx + PM2 برای اجرای همیشگی سرور)

نکته: چون دیتابیس SQLite یک فایل است، مطمئن شوید سرویس هاستینگ شما اجازه‌ی ذخیره‌سازی فایل دائمی (Persistent Storage/Volume) می‌دهد — بعضی سرویس‌های رایگان بعد از هر بار ری‌استارت فایل‌ها را پاک می‌کنند.

اگر هر کدام از این گزینه‌ها را انتخاب کردید و کمک لازم داشتید برای دیپلوی، خبر بدهید تا مرحله‌به‌مرحله راهنمایی کنم.

## امنیت

- رمز عبور پنل مدیریت را حتماً قوی انتخاب کنید و در `.env` نگه دارید (این فایل هرگز نباید به‌صورت عمومی یا در گیت‌هاب آپلود شود).
- محدودیت تعداد درخواست (Rate Limit) روی فرم‌ها فعال است تا از اسپم جلوگیری شود.
